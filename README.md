# E-Commerce Sales & Customer Analytics

## Overview

A relational e-commerce database and sales analytics project
developed using Microsoft SQL Server and T-SQL.

## Objectives

- Design a normalized relational database
- Manage customer and product information
- Track orders and order details
- Analyze payments and deliveries
- Analyze product reviews and inventory
- Generate business insights using SQL

## Database Schema

The database contains 10 interconnected tables:

- Customers
- CustomerAddresses
- Categories
- Products
- Orders
- OrderDetails
- Payments
- DeliveryDetails
- Reviews
- Inventory

## Technologies

- Microsoft SQL Server
- T-SQL

## Key SQL Concepts

- SELECT
- WHERE
- ORDER BY
- JOINs
- GROUP BY
- Aggregate Functions
- Subqueries
- CTEs
- Window Functions

## Business Questions

The project is designed to answer questions such as:

- Which products generate the most revenue?
- Which customers place the most orders?
- Which categories perform best?
- What are the monthly sales trends?
- Which products have low inventory?
- Which payment methods are most frequently used?
- How is delivery performance distributed?
